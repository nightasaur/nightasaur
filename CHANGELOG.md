# Changelog

All notable changes to the Nightasaur project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-09-07

### 🎉 Initial Open Source Release

#### 🚀 Features
- **AI Digital Spirit System**: Create, evolve, and interact with AI spirit companions
  - 10 elemental types (FIRE, WATER, LIGHT, SHADOW, STAR, ILLUSION, MOON, NATURE, THUNDER, ICE)
  - 6 evolution stages (EGG → HATCHLING → JUVENILE → ADULT → ULTIMATE → LEGENDARY)
  - Interactive dialogue with memory context
  - Visual evolution through AI image generation (ComfyUI)
  - Customization system (outfits, accessories, expressions)

- **Personal AI Assistant**
  - General knowledge Q&A
  - Code assistance (explain, debug, optimize, rewrite)
  - Multi-language translation (8 languages)
  - Document analysis (summarize, analyze, extract key info)

- **Full-Stack Platform**
  - Modern web interface (React + TypeScript + Vite + Tailwind)
  - Robust backend API (Node.js + Express + Prisma)
  - AI engine with local LLM support (Python + FastAPI + Ollama)
  - Mobile app ready (React Native + Expo)
  - Social media integration (Facebook/Instagram)

- **Multi-Language System**
  - 5 languages supported (zh-TW, zh-CN, en-US, ja-JP, ko-KR)
  - Auto-detect language preference
  - Interface translation system

#### 🏗️ Architecture
- Monorepo workspace (npm workspaces)
- Microservices architecture
- PostgreSQL database with Prisma ORM
- Redis caching layer
- Docker deployment support
- CI/CD ready (Vercel + Railway)

#### 📦 What's Included
- Source code (MIT licensed)
- Complete API documentation
- Development guide
- Deployment guide
- Contribution guidelines
- Code of conduct
